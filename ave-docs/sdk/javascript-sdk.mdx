## Import paths

| Import | Contents | Runtime |
|---|---|---|
| `@ave-id/sdk` | PKCE and OAuth helpers, `AveSession`, storage adapters, encryption helpers, `verifyJwt` | Any |
| `@ave-id/sdk/client` | `startPkceLogin`, `finishPkceLogin`, `completeOAuthCallback` | Browser |
| `@ave-id/sdk/server` | `verifyAveIdToken`, `verifyAveIdTokenFromAuthHeader`, `exchangeCodeServer`, `refreshTokenServer` | Server |
| `@ave-id/sdk/app-key` | Fragment parsing and stripping helpers | Any |
| `@ave-id/sdk/app-encryption` | Public-key lookup, `encryptForAppUser`, `decryptFromAppSender` | Any with Web Crypto |
| `@ave-id/sdk/session` | `AveSession` and `snapshotFromTokenResponse` | Any |
| `@ave-id/sdk/session-storage` | `createLocalStorageAdapter`, `createMemoryStorage`, `createSecureStoreAdapter` | Any |

## Sign in with an encryption key

```ts
import { AveSession, createLocalStorageAdapter } from "@ave-id/sdk";
import { completeOAuthCallback, startPkceLogin } from "@ave-id/sdk/client";

const oauth = { clientId: "YOUR_CLIENT_ID", redirectUri: "https://yourapp.com/callback" };
const session = new AveSession({ oauth, storage: createLocalStorageAdapter() });

// Sign-in button
await startPkceLogin({ ...oauth, scope: "openid profile offline_access e2ee:symmetric" });

// Callback page
await completeOAuthCallback(session, oauth);
const appKeyBase64 = session.getAppKeyBase64();
```

## Verify tokens on your server

```ts
import { verifyAveIdTokenFromAuthHeader } from "@ave-id/sdk/server";

const principal = await verifyAveIdTokenFromAuthHeader(request.headers.get("authorization"), {
  clientId: process.env.AVE_CLIENT_ID!,
});
```

`principal.subject` is the identity ID. `principal.claims` holds the verified `id_token` claims.

## Expo

Expo native has no Web Crypto digest. Configure `expo-crypto` once at startup:

```ts
import * as ExpoCrypto from "expo-crypto";
import { configureAveSdkForExpo } from "@ave-id/sdk/expo-session";

configureAveSdkForExpo(ExpoCrypto);
```

See [Expo with AuthSession](/guides/expo-auth-session).
