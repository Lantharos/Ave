Everything on this page is exported from `@ave-id/sdk`. The fragment helpers are also available from `@ave-id/sdk/app-key`, and the lookup and encryption helpers from `@ave-id/sdk/app-encryption`. For concepts and a walkthrough, see [End-to-end encryption](/guides/end-to-end-encryption).

## Scopes

```ts
import { E2EE_RESET_SCOPE, E2EE_SCOPES } from "@ave-id/sdk";

E2EE_SCOPES.SYMMETRIC;  // "e2ee:symmetric"
E2EE_SCOPES.ASYMMETRIC; // "e2ee:asymmetric"
E2EE_RESET_SCOPE;       // "e2ee:reset"
```

Add one mode scope to every sign-in. Add `E2EE_RESET_SCOPE` only when you intend to rotate keys.

```ts
import { buildAuthorizeUrl, E2EE_SCOPES } from "@ave-id/sdk";

const url = buildAuthorizeUrl(
  { clientId, redirectUri },
  { scope: ["openid", "profile", E2EE_SCOPES.ASYMMETRIC], state, nonce, codeChallenge },
);
```

## Reading keys from the callback

`completeOAuthCallback`, `finishPkceLogin`, `completeExpoOAuthCallback`, and the embed's `onTokens` already merge the keys into the token response. Use these helpers when you exchange the code yourself.

### `mergeAppEncryptionFromUrl(url, tokens)`

Returns a copy of `tokens` with every key found in the URL fragment: `app_key`, `app_public_key`, `app_private_key`, their `_old` counterparts, and `app_key_reset`.

```ts
function mergeAppEncryptionFromUrl(url: string | URL, tokens: TokenResponse): TokenResponse
```

`mergeAppKeyFromUrl` does the same for `app_key` only.

### `stripSensitiveFragmentParams(url?)`

Removes key parameters from the current URL with `history.replaceState`, leaving other fragment parameters in place. Call it as soon as the keys are read.

### `extractAppKeyFromUrl(url)` and related

```ts
extractAppKeyFromUrl(url);           // app_key
extractAppPublicKeyFromUrl(url);     // app_public_key
extractAppPrivateKeyFromUrl(url);    // app_private_key
extractAppKeyOldFromUrl(url);        // app_key_old
extractAppPublicKeyOldFromUrl(url);  // app_public_key_old
extractAppPrivateKeyOldFromUrl(url); // app_private_key_old
extractAppKeyResetFromUrl(url);      // true when app_key_reset is set
```

Each returns the base64 value, or `null` when absent. Values are already normalized with `normalizeAppKeyBase64`, which restores `+` characters that `URLSearchParams` decodes as spaces.

### `stripSensitiveHashFromUrlString(url)` and `stripOAuthQueryParamsFromUrlString(url)`

Return a copy of a URL string without key fragment parameters, or without OAuth query parameters. Use them before logging or displaying a callback URL.

## Keys in `AveSession`

```ts
session.getAppKeyBase64();          // string | undefined
session.getAppPublicKeyBase64();    // string | undefined
session.getAppPrivateKeyBase64();   // string | undefined
await session.setAppKeyBase64(key); // replace, or pass null to clear
```

After a rotation, `session.getState().snapshot` also holds `appKeyBase64Old`, `appPublicKeyBase64Old`, `appPrivateKeyBase64Old`, and `appEncryptionWasReset`.

## Public-key lookup

Lookups need no user token and return only data for identities that authorized your client ID with `e2ee:asymmetric`.

### `lookupAppPublicKeyByHandle(config, handle)`

```ts
function lookupAppPublicKeyByHandle(
  config: { clientId: string; issuer?: string },
  handle: string,
): Promise<AppEncryptionUserRecord>
```

### `lookupAppUserByPublicKey(config, publicKey)`

```ts
function lookupAppUserByPublicKey(
  config: { clientId: string; issuer?: string },
  publicKey: string,
): Promise<AppEncryptionUserRecord>
```

```ts
interface AppEncryptionUserRecord {
  clientId: string;
  identityId: string;
  handle: string;
  displayName: string;
  publicKey: string;       // base64 SPKI, P-256
  encryptionMode: string;  // "asymmetric"
}
```

Both throw `AppEncryptionLookupError` on failure. Its `status` is `404` when the identity does not exist, has not authorized your app, or has no public key yet.

```ts
import { AppEncryptionLookupError, lookupAppPublicKeyByHandle } from "@ave-id/sdk";

try {
  const recipient = await lookupAppPublicKeyByHandle({ clientId }, "alice");
} catch (error) {
  if (error instanceof AppEncryptionLookupError && error.status === 404) {
    showInvite("alice");
  }
}
```

## Encrypting for another user

### `encryptForAppUser(payload, recipientPublicKey)`

Encrypts `payload` for the holder of `recipientPublicKey`. It generates an ephemeral P-256 key, derives an AES-256-GCM key with ECDH, and encrypts with a random 12-byte IV.

```ts
function encryptForAppUser(
  payload: string | Uint8Array | ArrayBuffer,
  recipientPublicKey: string,
): Promise<AppEncryptedPayload>

interface AppEncryptedPayload {
  encryptedPayload: string; // base64 of IV followed by ciphertext
  senderPublicKey: string;  // base64 SPKI of the ephemeral key
}
```

### `encryptForAppHandle(payload, params)`

Looks up the recipient by handle, then calls `encryptForAppUser`.

```ts
function encryptForAppHandle(
  payload: string | Uint8Array | ArrayBuffer,
  params: { clientId: string; handle: string; issuer?: string },
): Promise<AppEncryptedPayload>
```

### `decryptFromAppSender(envelope, privateKeyBase64)`

Decrypts an `AppEncryptedPayload` with the recipient's `app_private_key`.

```ts
function decryptFromAppSender(
  envelope: AppEncryptedPayload,
  recipientPrivateKeyBase64: string,
): Promise<ArrayBuffer>
```

### `importAppPrivateKey(privateKeyBase64)`

Imports `app_private_key` as a non-extractable ECDH `CryptoKey` for your own key agreement code.

## Example

```ts
import { decryptFromAppSender, encryptForAppHandle } from "@ave-id/sdk";

// Sender
const envelope = await encryptForAppHandle(JSON.stringify({ roomKey }), { clientId, handle: "alice" });
await api.sendInvite({ to: "alice", envelope });

// Recipient
const plaintext = await decryptFromAppSender(envelope, session.getAppPrivateKeyBase64()!);
const { roomKey } = JSON.parse(new TextDecoder().decode(plaintext));
```
